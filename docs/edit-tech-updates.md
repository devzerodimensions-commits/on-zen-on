# Edit Tech Updates

In Admin → Pages, open an article by title to edit its hero image, introduction, article sections, reference link, related articles and SEO fields. Save draft and Publish to update the live page.

The Tech Updates page is the article index. Its Updates section holds the article cards. The Home page has its own Updates section at the existing updates anchor with the three homepage cards. Edit each card's title, description, image and destination there. Cards are editorial selections: updating an article title or cover does not automatically rewrite its cards on other pages.

To add a future article, create a page under /blog/ with a hero and About sections, publish it, then add its card to Tech Updates and optionally Home. The header Tech Updates link points to /tech-updates and is editable under Menus.

This release seeds three articles and the index once. Later restarts preserve admin changes and unpublished states. All three images are available in the media picker and can be replaced by uploads.

The respective subjects were (1) a professional reviewing a customer support conversation and simple workflow on a monitor; (2) a developer workstation with code on a laptop and coordinated interfaces on a tablet and phone; (3) a security engineer reviewing a laptop beside network equipment. Images are illustrative rather than client case studies.
