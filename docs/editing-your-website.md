# Editing your website

1. Open Admin and choose Pages. Select the page you want to change.
2. Open a section. Text content, Images, and Buttons and links are grouped separately on branded sections. Other sections have clear heading, content, image and card controls.
3. Use Upload a new image to replace a picture. Describe the picture for visitors using screen readers.
4. Use Add section to choose a banner, text and image, services, gallery, FAQs, inquiry form, or another available layout. Move up/down changes the order.
5. Save draft keeps changes private. Preview lets you inspect a saved page. Publish updates the website.

## New pages
Choose Create page, enter its name and website address, and select a starter: Service, About, Article or Simple page. Edit the supplied sections, complete Search & sharing, preview and publish. Add a link in Menus so visitors can find it. The article starter creates an editable page; homepage blog cards are managed separately on Home.

## Theme and motion
Open Site settings, then the existing On Zen On settings entry. Under Website appearance, enable custom theme settings to use font families, paragraph/heading sizes, line spacing, six color controls, rounded corners, section spacing, and desktop/mobile logo sizes. The example preview responds immediately. Save draft then Publish to apply changes. Restore original design disables the custom theme; publish to restore it publicly.

The custom theme controls the shared styling described beside each control. It does not import WordPress themes or plugins. Keep background/text and button colors readable. Theme drafts show an example preview; public page previews use the currently published theme.

The motion switch is in the website experience settings. When enabled, public sections and content cards fade gently into view once per page visit. Visitors who request reduced motion do not get these entrance animations.

## Shared content
Reusable sections includes the header and footer. Menus manages navigation links. Media library stores uploaded images. Inquiries receives public contact form submissions. Requests manages portal requests and booking requests.
